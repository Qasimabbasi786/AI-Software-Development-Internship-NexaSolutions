# Part I: Ecosystem Awareness (MCP, Semantic Kernel & Local Models - Stretch)

## Objectives
- Evaluate the wider autonomous agent landscape beyond LangChain/LangGraph:
  - **Model Context Protocol (MCP)**: Standardized cross-platform tool servers and exposure mechanisms.
  - **Microsoft Semantic Kernel**: Native C#/.NET agent orchestration and plugin integration.
  - **Local Small Language Models**: Running quantized models (via Ollama) for cheap, low-latency intent routing.

## Deliverables
- Technical report comparing MCP with in-repo LangChain tools in `../docs/week7-mcp-vs-langchain-tools.md`.
- Technical report comparing Semantic Kernel with LangGraph in `../docs/week7-semantic-kernel-comparison.md`.
- (Optional) Hands-on Ollama classification benchmark on 15 intent test messages.
