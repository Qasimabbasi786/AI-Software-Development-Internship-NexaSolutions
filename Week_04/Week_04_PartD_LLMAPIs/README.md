# Week 4 - Part D: LLM APIs in Depth

## 🎯 Objectives
- Understand model parameters: `temperature` (randomness/creativity vs determinism) and `max_tokens`.
- Master conversation history management across stateless LLM API requests.
- Implement token streaming to reduce time-to-first-token latency.
- Enforce and parse structured JSON responses reliably, handling parse failures gracefully.

## 📂 Included Practice Scripts
1. `01_conversation_history.py`: Multi-turn state simulation.
2. `02_streaming.py`: Token stream simulation and consumption.
3. `03_structured_output.py`: Defensive JSON extraction and fallback parsing.
